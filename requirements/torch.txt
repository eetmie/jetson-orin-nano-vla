# resolver will happily replace the JetPack-matched wheel, and a torch that cannot

# with no error. Install lerobot first, force the JetPack-matched torch back on top,
# then verify torch.cuda.is_available().
#
#   pip install -r requirements/torch.txt
#   pip install --force-reinstall --no-deps torch torchvision \
#       --extra-index-url https://pypi.jetson-ai-lab.io/sbsa/cu130
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# scripts/10_env_torch.sh does exactly this.
#
# There is no `jp7` index on Jetson AI Lab — the CUDA 13 aarch64 wheels live under
# `sbsa`. Same index the ONNX Runtime build comes from.
